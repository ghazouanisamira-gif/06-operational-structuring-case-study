# Management Routine

## Objective

Create a regular management rhythm that connects operational activity with decisions and improvement actions.

## Review Cycle

**Prepare → Review → Decide → Assign → Follow Up**

## Management Review

| Topic | Question |
|---|---|
| Performance | Are KPIs on track? |
| Customer Journey | Where are the main drop-offs? |
| Operations | Where are execution gaps? |
| Risks | What could affect performance? |
| Actions | What needs to be done? |
| Improvement | What should be changed? |

## Action Tracking

| Action | Owner | Priority | Due Date | Status | Effectiveness |
|---|---|---|---|---|---|
| | | | | | |

## Governance Principle

Every important issue should lead to a clear:

**Owner + Action + Deadline + Follow-up**
