# Management Routine

## Objective

Create a regular management rhythm connecting operational activity, data, decisions, actions and follow-up.

## Review Cycle

**Prepare → Consolidate → Review → Challenge → Decide → Assign → Follow Up**

## Management Review

| Topic | Question |
|---|---|
| Performance | What is happening? |
| Funnel / Customer Journey | Where are the main drop-offs? |
| Operations | Where are execution gaps? |
| Data | Is the information reliable enough for a decision? |
| People | Where is coaching or support required? |
| Risks | What could affect performance or continuity? |
| Actions | What needs to be done? |
| Improvement | What should be changed? |
| Follow-up | Did the action produce the expected effect? |

## Action Tracking

| Action | Owner | Priority | Due Date | Status | KPI / Evidence | Effectiveness |
|---|---|---|---|---|---|---|
| | | | | | | |

## Management Loop

**Data → Analysis → Decision → Action → Follow-up → Adjustment**

This turns reporting into an active management mechanism.

## Governance Principle

Every important issue should lead to:

**Owner + Action + Deadline + Expected Outcome + Follow-up**
