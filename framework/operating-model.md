# Operating Model

## Objective

Create a clear structure connecting customer-facing activities, operational execution, performance measurement and management decisions.

## Operating Logic

**Demand / Lead → Qualification → Conversion → Follow-up → Performance Monitoring → Management Action**

## Core Components

| Component | Purpose |
|---|---|
| Process | Define how work flows |
| Roles | Clarify ownership |
| Documentation | Standardize execution |
| KPIs | Measure performance |
| Dashboard | Create visibility |
| Governance | Enable decisions |
| Improvement | Sustain progress |

## Design Principle

An operating model should answer five questions:

1. What needs to be done?
2. Who owns it?
3. How is it performed?
4. How is performance measured?
5. What happens when performance deviates?

## Management Cycle

**Plan → Execute → Measure → Review → Act → Improve**
